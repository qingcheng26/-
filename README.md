# 回复助手 · 手机版

手机上用的回复稿助手：粘贴（或**分享**）对方发来的消息，拿到几条能直接发出去的回复，
挑一条复制走。另外还带一档「聊天」——用「大肥鱼」的身份陪你说话。

**发不发、发哪条永远是你自己按的。** 它不连任何社交平台、不自动发消息、不后台轮询，
只做一件事：把话组织好，剩下的你决定。

## 在线用

部署到 GitHub Pages 之后，地址形如
`https://<你的用户名>.github.io/<仓库名>/`。

手机打开后，**用浏览器的「添加到主屏幕」**装一下 —— 那样它就是个独立 App
（有自己的图标、独立窗口、支持系统分享），不是浏览器标签。

### 装成 App 之后的用法（最省事）

**长按对方那条消息 → 分享 → 回复助手 → 自动出稿 → 点一条（已复制）→ 回聊天长按粘贴**

少了「复制」和「手动切 App」两步。

### 没装成 App 的用法

1. 长按对方的消息 → 复制
2. 打开本页 → 点「读取剪贴板」（或直接长按输入框粘贴）
3. 点「生成回复」，挑一条
4. 点那条草稿 → 已复制 → 切回去长按粘贴

## 手机端做不到什么（这是系统限制，不是没做）

- **手机不让一个 App 读别的 App 里的文字。** Android/iOS 的沙箱就是这么设计的。
  所以**没有**「全局热键 + 自动读取聊天窗口」那种能力 —— 想读只能靠「复制」或「系统分享」，
  都要你主动点一下。
  （技术上能用无障碍服务绕过，但那是安卓上权限最大的 API，能看到屏幕上的一切，
  包括密码框；Google Play 也限制这类用途。不值得为了省两步就交出去。）
- **剪贴板 API 需要 https。** 本地 `http://` 打开时用不了 → 代码有兜底：
  复制失败时自动帮你把文字**选中**，长按点「复制」即可。

## 五档语气

| 档 | 什么时候用 |
|---|---|
| **亲和** | 不想把关系搞僵。先接住对方的情绪，再讲内容 |
| **讲理** | 吵起来了要靠道理赢。抓对方论证里的具体毛病，咬住不放 |
| **回怼** | 不想讲道理，就想让对方噎住。短、脆、不客气 |
| **阴阳** | 表面客气实则讽刺。越礼貌越扎心 |
| **聊天** | 不是回别人，是**跟「大肥鱼」说话**。高情商、语气温柔 |

有一条线写死在提示词里：**可以尖锐、可以刻薄，但不出现脏话、人身攻击和威胁。**
这不是道德洁癖 —— 真吵出事了，威胁和辱骂是**对你自己不利的证据**。

同理，**明令禁止编造事实**：不许虚构数据、案例、法条、「研究表明」。
某条回复非要有具体事实撑着而模型给不出时，它会写 `〔建议你补一个具体例子〕` 占位让你填 ——
编出来的论据被对方当场戳穿，比不会回复还难看。

## 设置

点右上角 ⚙：

| 项 | 说明 |
|---|---|
| API Key | DeepSeek 的 `sk-` 密钥，**只存在你自己这台设备的浏览器里** |
| 上游地址 | 默认 `https://api.deepseek.com`，填中转站也行 |
| 模型 | flash（便宜快）/ pro（强） |
| 每次给几条 | 1–5，默认 3 |

> **密钥怎么填**：从 DeepSeek 平台复制之后，**直接填进这个设置界面，不要贴到任何对话或 issue 里**。
> 它只会发给你填的那个上游地址，不经过任何别的地方 —— 本项目没有后端。

## 技术上的几件事

- **纯前端，没有后端。** 浏览器的 `fetch` 直连 DeepSeek 的 `/chat/completions`。
  实测官方 API 的 **CORS 是放开的**（预检和实际 POST 都回 `access-control-allow-origin`），
  所以不需要服务器中转，**密钥也不必交给任何第三方**。
- **每次生成都真的花你 key 的钱**，界面底部显示本次金额。高峰时段（工作日 9-12、14-18）
  价格是空闲时段的两倍，页头会显示当前处于哪个时段。
- **配置和对话存在 localStorage**，换浏览器/清缓存就没了。
- **`index.html` 是单文件**：提示词、解析、计价、界面全在里面，头像 base64 内联。
- **Service Worker 只做「能装成 App」**，不缓存 API 响应 —— 那会把余额和草稿都存下来。

**「大肥鱼」（DeepSeek 鲸鱼娘）**，**不是 DeepSeek 官方角色**。

- 角色设定文档在该仓库的 `docs/角色设定.md`
- 该项目许可允许使用/修改/分享/商用，**须署名**作者 YunYueSama 和仓库地址

人设正文在 `index.html` 的 `PERSONA` 常量里。里面有几条是那个设定的硬要求，**删了会跑偏**：
不叫「主人」、不写恋爱关系、最多点一次贪吃、不因为用户忙或隔久了才来就让他内疚。

图标基于上述立绘生成，因此沿用同样的署名要求。
