# 回复助手 · 手机版

手机上用的回复稿助手：粘贴对方发来的消息，拿到几条能直接发出去的回复，挑一条复制走。
另外还带一档「聊天」——用「大肥鱼」的身份陪你说话。

**发不发、发哪条永远是你自己按的。** 它不连任何社交平台、不自动发消息、不后台轮询，
只做一件事：把话组织好，剩下的你决定。

## 先说清楚手机端做不到什么

PC 版有个「全局热键 + 自动抓取选中文字」，**这两样在手机上都做不了**：

- **手机不让一个 App 读别的 App 里的文字。** 这是 Android/iOS 的沙箱设计，
  不是没实现 —— 想读只能靠「复制」或「系统分享」，都要你主动点一下。
- **没有全局热键。** 也没有「悬浮窗自动抓当前聊天内容」这种能力（那需要无障碍权限，
  等于把自己的手机完全交给一个程序，不值得）。

所以手机端的用法是**四步**，比 PC 版多一步：

1. 在聊天软件里**长按对方那条消息 → 复制**（或者**分享 → 回复助手**）
2. 切到回复助手（或在分享面板里直接选它）
3. 点「生成回复」，挑一条
4. 点那条草稿 → 已复制 → 切回聊天软件**长按粘贴**

## 怎么让它跑到手机上

### 路线 A：局域网打开（最快，不用发布到网上）

1. 双击 `run_server.bat`
2. 会打印一个网址和一个**二维码**
3. 手机连**同一个 WiFi**，扫码或手输网址

**这条路的代价（用 http:// 打开必然如此）：**
- 剪贴板 API 用不了 → 代码里有兜底：点草稿时**自动帮你把文字选中**，
  你长按点「复制」就行，不用自己划选
- 装不到主屏幕（Service Worker 需要 https）

### 路线 B：https 托管（完整体验）

把它放到任何一个 https 静态托管上（GitHub Pages / Cloudflare Pages 都行），
手机打开那个网址 →「添加到主屏幕」。这样：

- 点草稿就能**自动复制**
- 装到主屏幕后是个**独立 App**，有自己的图标，不是浏览器标签
- **API Key 仍然只存在你手机里**，托管方看不到（它是纯前端，密钥直接发给 DeepSeek）

> 要发布到公网的话得先想清楚：**页面本身是公开的**。
> 别人打开只会看到一个没配 key 的空壳（key 在你手机的 localStorage 里，
> 不在代码里），但这件事还是你自己决定。

## 设置

点右上角 ⚙：

| 项 | 说明 |
|---|---|
| API Key | DeepSeek 的 `sk-` 密钥，**只存在这台手机里** |
| 上游地址 | 默认 `https://api.deepseek.com`，填中转站也行 |
| 模型 | flash（便宜快）/ pro（强） |
| 每次给几条 | 1–5，默认 3 |

> **密钥怎么填**：从 DeepSeek 平台复制之后，**直接填进设置界面，不要贴到对话里**。
> 它只会发给你填的那个上游地址，不经过任何别的地方。

## 技术上的几件事（改代码前看）

- **纯前端，没有后端。** 浏览器的 `fetch` 直接打 DeepSeek 的
  `/chat/completions`，实测 **CORS 是放开的**（预检和实际 POST 都回
  `access-control-allow-origin`），所以不需要任何服务器中转，密钥也不用交给第三方。
- **费用提醒**：手机上生成的每一次都真的花你 key 的钱，界面底部会显示本次金额。
- **配置和对话存在 localStorage**，换浏览器/清缓存就没了。API Key 也在里面。
- **`index.html` 是单文件**：提示词、解析、计价、界面全在里面。
  头像 base64 内联，所以整个页面只有 5 个文件（html + manifest + sw + 两个图标）。
- **Service Worker 只做「能装成 App」**，不缓存 API 响应 —— 那会把余额和草稿都存下来。

## 验证到哪一步

**已经在真实浏览器里跑通的**（移动端视口 375×812）：

- 页面渲染、五个语气按钮、对话流、草稿卡
- 30 项纯逻辑测试：五档提示词（含人设红线）、对话角色名、解析三级兜底、
  计价（高峰=空闲两倍等）—— 全过
- **真 API 端到端**：讲理档 3.5 秒出 3 条草稿、¥0.0019；聊天档 3.9 秒出 3 条、¥0.0021，
  人设对（「在的。你说行不通——是卡在哪一步了？」）
- 聊天档左右归属（用计算样式核过，不是靠眼看）

**没验证的**（需要你的真手机）：

- **点草稿到底能不能自动复制** —— 我测试时走的是脚本点击，浏览器**不认**它是用户手势，
  所以剪贴板被拒了。真手指点应该是可以的，但**我没法证明**。
  不行的话会自动退到「帮你选中文字、长按复制」，那条路一定有。
- 手机上「长按粘贴」、分享面板里出现「回复助手」（这个依赖装成 PWA，路线 B 才有）
- 局域网扫码能不能连上（取决于你的 WiFi 有没有做客户端隔离）

## 跟 PC 版的关系

两个独立项目，各自能单独跑：

- `桌面\回复助手\` —— PC 版（Python + PySide6，全局热键 + 自动抓取）
- `桌面\回复助手手机版\` —— 这个（纯前端）

**提示词、解析、计价这三块是逐字一样的**（一边改了要同步另一边）。
`reply/brain.py` ←→ `index.html` 里的 `systemPrompt` / `parseDrafts` / `estimateCost`。
